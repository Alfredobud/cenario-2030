# Cenário 2030

Exercício de **ficção especulativa** sobre um futuro possível em 2030: crise europeia, migração de europeus para o Brasil e a Rússia, e a camada de teorias da conspiração que circula em paralelo à geopolítica.

> Este repositório é narrativa, não análise factual. Onde a ficção se apoia em fatos históricos reais, isso está indicado como "âncora real".
