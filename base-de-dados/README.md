# Base de dados

Material bruto e fichamentos de fontes (vídeos, lives, artigos, documentos) usados para construir e ajustar os capítulos do Cenário 2030.

**Como usar:**
- Cada fonte vira um arquivo de fichamento, com identificação, teses, dados citados, status de verificação e sugestões de onde usar nos capítulos.
- Os dados ficam marcados como **a verificar** até serem checados. Só entram nos capítulos como "âncora real" depois de checados.
- As opiniões e o enquadramento do autor da fonte são registrados como **posição da fonte**, não como fato.
